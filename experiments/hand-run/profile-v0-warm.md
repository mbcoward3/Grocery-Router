# Household profile v0 — warm

*Written by hand, as if the system had produced it (§Next session, item 4). If a useful
one can't be written from what's already known, the format is wrong.*

**The rule that governs this document: no claim without a trace (§2).** Every line in the
Taste and Patterns sections carries its evidence inline. At v0 the honest trace is often
"we know this about ourselves" — that is self-report, and it is allowed here for the same
reason the 60 recipes enter the corpus directly (§4: proven-or-attested). What is *not*
allowed is a claim with no trace at all. If you can't say why you believe a line, cut it.
A profile that quietly accumulates ungrounded assertions is the §13 failure mode, and it
poisons everything downstream.
