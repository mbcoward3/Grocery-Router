# Visual design direction

Type: prototype
Status: open
Blocked by: 02

## Question

What does Grocery Router look like?

The stated requirement is *"whatever can get us the best looking UI"*, and that decision
drove the whole frontend stack (decision 4). So the aesthetic is a real deliverable, not a
finishing pass.

Settle:

- **A direction.** Propose three or four distinct visual directions for this brief — a
  weekly household ritual, read at a kitchen table on Sunday and in a supermarket aisle on
  Monday. Give each a background and accent colour, a typeface pairing, and a one-line
  rationale. Pick one. Do not settle for a default component-library look.
- **The type scale and the density.** The week screen is five dense cards. The list screen
  is forty short lines read at arm's length. These want different densities.
- **Light and dark**, and which one the kitchen actually uses.
- **The component inventory** the frontend needs, so the spec can name it.
- **What signals uncertainty.** This product refuses to guess, and it says so constantly:
  *unknown yield*, *not scaled*, *sides not included*, *no outcome recorded*. Those are not
  errors and they must not look like errors. Design that state before anything else.
